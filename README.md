# 🛍️ Shoplytics  
## Customer Behavior Analysis with PostgreSQL & Power BI


---

## 📌 Project Overview  

**Shoplytics** is an end-to-end **customer behavior analytics project** that transforms raw customer data into meaningful business insights.  
The project demonstrates the complete data analytics pipeline — starting from a **CSV dataset**, performing **Exploratory Data Analysis (EDA)**, storing and querying data using **PostgreSQL**, and finally creating an **interactive Power BI dashboard**.

---

## 🎯 Project Objectives  

- Analyze customer purchasing behavior  
- Identify high-value customers  
- Study the impact of discounts on sales  
- Compare spending patterns across customer segments  
- Build a business-ready interactive dashboard  

---

## 🧩 Dataset  

- Format: **CSV**
- Contains customer-related data such as:
  - Customer demographics  
  - Purchase amounts  
  - Discounts applied  
  - Product categories  
  - Review ratings  

---

## 🔄 Project Workflow  

CSV Dataset
↓
Exploratory Data Analysis (EDA)
↓
PostgreSQL Database
↓
SQL Queries & Aggregations
↓
Power BI Dashboard

---


---

## 🔍 Exploratory Data Analysis (EDA)  

- Checked for missing and inconsistent values  
- Analyzed purchase amount distribution  
- Performed gender-wise and category-wise analysis  
- Studied discount vs purchase behavior  

EDA helped in understanding hidden patterns and preparing the data for database-level analysis.

---

## 🗄️ Database & SQL Analysis  

- Imported cleaned data into **PostgreSQL**  
- Created structured tables with proper data types  
- Executed SQL queries to:
  - Calculate total and average sales  
  - Segment customers based on behavior  
  - Analyze product performance  


### 📊 Power BI Dashboard

- Connected PostgreSQL directly to **Power BI**
- Designed an interactive dashboard featuring:
  - KPI cards (Total Revenue, Average Purchase)
  - Bar charts and pie charts
  - Filters for gender, product category, and discounts

The dashboard enables quick, data-driven decision-making by providing clear insights into customer behavior.

---

### 🛠️ Tools & Technologies

| Tool | Purpose |

### 📈 Key Insights

- Certain customer segments show significantly higher spending
- Discounts have a strong influence on purchase behavior
- Some product categories consistently receive higher ratings
- Interactive dashboards help identify trends quickly
